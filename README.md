# Kafka на пальцах

Интерактивный разбор Apache Kafka: не текст про механику, а работающие стенды,
на которых механику видно. Сделано в духе [tryrabbitmq.com](https://tryrabbitmq.com/) —
одна страница, простые фигуры, всё можно потрогать.

Каждая глава — короткий текст плюс живой стенд: лента партиции с оффсетами,
закладки консьюмеров, полёт записи от продюсера, ISR, lag, ребалансы.

## Как открыть

Просто открой `index.html` двойным кликом — сборка не нужна, зависимостей нет.

Если браузер ограничивает локальные файлы, подними любой статический сервер:

```bash
python -m http.server 8080
```

и зайди на `http://localhost:8080`.

## Главы

| № | Глава | Что на стенде |
|---|-------|---------------|
| 01 | Лог, а не очередь | очередь и лог бок о бок: слева сообщение исчезает, справа двигается только закладка |
| 02 | Топик и партиции | пропускная способность: один лог против четырёх |
| 03 | Offset | один и тот же offset в разных партициях — разные сообщения |
| 04 | Ключ и порядок | живая формула `hash(ключ) % N`, полёт записи, перекос ключа |
| 05 | Consumer group | раздача партиций, простаивающие копии, ребаланс |
| 06 | Committed offset и lag | поток в реальном времени, `lag = LEO − committed` |
| 07 | Commit: авто и ручной | посекундный сценарий тихой потери сообщения |
| 08 | Retention | время идёт, лог съедает начало, отставший консьюмер ловит `OffsetOutOfRange` |
| 09 | Compaction | история превращается в снимок состояния, tombstone |
| 10 | Репликация и ISR | лидер, реплики, выпадение из ISR, выборы |
| 11 | acks и min.insync | лаборатория отказа: тихая потеря против явной ошибки |
| 12 | Гарантии доставки | конвейер до внешней базы, дубли, границы exactly-once |
| 13 | Что ломается в проде | диагностика lag по партициям, шторм ребалансов |
| 14 | Песочница | всё вместе, свободная игра |
| 15 | Шпаргалка | Kafka против очередей, ответы для собеседования, глоссарий |

## Как это устроено

```
index.html            подключает всё; порядок скриптов важен
assets/theme.css      дизайн-система: токены цвета, компоненты, обе темы
assets/core.js        библиотека KV: реестр глав, компоненты, лента партиции
assets/app.js         оболочка: навигация, роутинг, монтирование глав
scenes/NN-*.js        по файлу на главу
```

Чистый JS без сборки и без зависимостей. Скрипты классические (не модули),
поэтому страница работает и с диска, и с любого хостинга.

### Смысл цвета

Цвет несёт информацию, а не украшает:

- **янтарь** — запись, продюсер, конец лога (LEO);
- **бирюза** — чтение, консьюмер, закладки;
- **красный / зелёный** — потеря и сохранность;
- **палитра `k0…k5`** — ключи сообщений: один ключ = один цвет во всех главах.

### Добавить главу

Создай `scenes/16-моё.js` по образцу любой существующей и подключи его
в `index.html` перед `assets/app.js`:

```js
(function () {
  "use strict";
  var el = KV.el, ui = KV.ui, util = KV.util;

  KV.scene({
    id: "my", num: 16, group: "Прод", nav: "Моя глава",
    title: "Заголовок", lede: "Подводка.",
    build: function (root, api) {
      root.appendChild(ui.prose("<p>Текст.</p>"));
      var stage = ui.stage({ title: "Стенд" });
      // ...
      root.appendChild(stage.el);
      root.appendChild(ui.takeaway(["Что запомнить."]));
    }
  });
})();
```

Все таймеры — только через `api.interval` / `api.timeout` / `api.raf`:
они автоматически останавливаются при уходе с главы.

Цвета — только токенами (`var(--write)`, `util.keyColor(key)`), иначе глава
сломается в одной из двух тем.

Термины размечаются как `[[offset]]` или `[[offset|оффсет]]` — получится
подсказка при наведении. Список терминов — в `KV.glossary` (`assets/core.js`).
